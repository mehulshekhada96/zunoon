# Zunoon Club

Responsive Next.js static website for Zunoon Club — A Celebration of Life.

- English/Gujarati mixed default plus English, Gujarati and Hindi language choices.
- Six interactive club panels with thirty activity categories.
- Supplied event photographs, responsive gallery, category filters and keyboard-accessible lightbox.
- Annual membership pricing and separate activity fee explanation.
- WhatsApp membership enquiries and telephone/Instagram links.

Content is based on the supplied Zunoon Club PDF and relevant website requirements in the accompanying chat export. Private chat content is not bundled. Images are optimized derivatives of supplied originals. No online payment, registration database, event calendar or automated enrolment is enabled.

Run `npm run dev` for development; `npm run build` produces the static `out/` site. Hosting identity remains linked to the existing private preview.
