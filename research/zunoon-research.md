## Existing website and CSS audit

The old site is an **Angular** single-page app, not Next.js. Public routes in its bundle are empty-path redirect to homepage, header, homepage and footer. Sections include hero carousel, about, four benefits, growth panel, testimonials and contact/footer. Several footer links use `href="#"`, so they don't lead to dedicated content pages. No substantial ventures, groups or real photo gallery content appears in the downloaded homepage component.

Brand palette: charcoal/black (#0d0d0d, #111, #161616), white/off-white, and orange-red (#ff3b30, #e63922); #dc3545 also appears. Some extracted colors belong to Bootstrap and are not deliberate brand colors. New preview uses a restrained charcoal/white/red palette with generous whitespace and one strong red accent.

Typography: component CSS uses Segoe UI/Roboto/sans-serif and Georgia/serif. Global styles contain Bootstrap and Owl Carousel rules. External dependencies in HTML include Bootstrap 5.3.8, Bootstrap Icons 1.13.1 and Font Awesome 7.0.1. Avoid importing the old minified CSS into the new site: rewrite responsive styles and keep the original as research evidence.

Logo: `images/Logo.png`, 1750 × 524. Official supplied deck additionally shows an infinity motif with a red dot, Greek-letter group marks and venture wordmarks. Reuse the official logo rather than approximating it as text.

Old site images named `pexels-...` are **stock photos**; they are not evidence of actual Zunoon events. Testimonial image labels in the indexed site include generic names. Do not reuse testimonial portraits as verified member identities. Client must approve testimonials and supply matching real portraits.

`robots.txt` and `sitemap.xml` both returned the same Angular HTML shell, not valid robots/sitemap data. This was checked by comparing the response content, not by assuming status 200 meant a valid sitemap.

## Reference-site interpretation

LVB: detailed benefits, membership options, event proof, testimonials and strong contact calls to action. Use its clear membership journey; don't copy its fees or growth figures.

Progress Alliance: entrepreneur-focused mission, community imagery, holistic growth, values and learning. Use its clear story progression and emphasis on people; don't copy its membership/meeting figures.

Recommended visitor journey: promise → club evidence → why join → activities → ventures → Surat groups → leadership → gallery → enquiry.

## Preview implementation decisions

- Genuine Next.js App Router project with a static export for a simple client preview.
- Centralized content in `lib/content.ts` for easy updates.
- Real portrait extracts and verified venture/group names from the supplied presentation.
- Stock preview images explicitly labeled illustrative; no fabricated event dates.
- Membership/contact form opens a prefilled WhatsApp enquiry after a visitor explicitly chooses the button. It does not claim server-side submission, store personal data or pretend to have sent a message.
- Page metadata uses noindex until this concept is approved; no official-domain canonical claim.
